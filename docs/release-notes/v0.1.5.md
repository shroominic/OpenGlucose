# OpenGlucose 0.1.5

OpenGlucose 0.1.5 restores archived sensor-data export on current iOS versions.
It also includes the protected TestFlight delivery workflow that the release
owner uses for future tagged releases.

## Fixed

- On iPhone, archived sensor exports now open the native Apple share sheet on
  iOS 26.
- On iPad, the share sheet remains a correctly anchored popover.
- Before handing an export to iOS, the app accepts only its own scoped export
  cache files.

## TestFlight delivery

- The repository includes a protected, tag-bound TestFlight workflow. It is
  started manually from the exact stable release tag.
- External delivery has separate upload, beta-review, and tester-notification
  phases. Publishing a GitHub Release does not start any of these phases.
- Tester notification remains an explicit release-owner action after Apple
  approves the external beta review.

## Build tooling

- Android build tooling is aligned with Gradle 9.7 (#65). This maintenance
  update does not change Android app behavior.

## Download

On Android, expand **Assets** and download `openglucose-0.1.5+27.apk`.

OpenGlucose is wellness/reference software, not a medical device. Do not use it
for diagnosis, medication or insulin dosing, treatment decisions, or emergency
monitoring.

App version: `0.1.5` (build `27`)
