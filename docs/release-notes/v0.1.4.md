# OpenGlucose 0.1.4

OpenGlucose 0.1.4 makes the connected glucose experience consistently branded
without exposing the connected sensor name outside Settings. It also adds an
Apple Watch Smart Stack presentation while retaining iPhone-only sensor
Bluetooth ownership.

## What's new

- The connected dashboard title is now **OpenGlucose**.
- Android live glucose notifications use the **OpenGlucose** brand.
- iPhone Live Activities use the **OpenGlucose** brand, including the Lock
  Screen and Dynamic Island.
- The sensor name remains available in Settings and when selecting a sensor.
- The iPhone Live Activity can appear in the Apple Watch Smart Stack on iOS 18
  and watchOS 11. It is a display surface, not a separate Watch app or direct
  sensor Bluetooth connection.
- Glucose remains hidden by default in the Live Activity and Smart Stack. The
  iPhone setting to show glucose in the live notification controls both
  surfaces. Stale Watch content hides glucose again.

## macOS reviewer preview

The repository now includes an Apple-silicon macOS reviewer preview. It is
ad-hoc signed, has no direct stable-release download, and is not a supported
sensor platform. Physical AiDEX, Intel, privacy, signing, and notarization
validation are still required before a macOS sensor-support claim.

## Download

On Android, expand **Assets** and download `openglucose-0.1.4+25.apk`.

OpenGlucose is wellness/reference software, not a medical device. Do not use it
for diagnosis, medication or insulin dosing, treatment decisions, or emergency
monitoring.

App version: `0.1.4` (build `25`)
