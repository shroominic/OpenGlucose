# OpenGlucose v0.1.1 Beta

This hotfix improves Android sensor setup and makes Bluetooth recovery clearer
and safer.

## What's new

- Android now establishes the Bluetooth bond before subscribing to protected
  sensor notifications, allowing the system pairing dialog to appear on phones
  that require explicit bonding.
- Setup failures now explain whether Bluetooth, permissions, pairing, range,
  or possible use by another phone needs attention.
- Failed setup pauses automatic retry and offers **Try again** or
  **Choose another sensor** instead of repeatedly reconnecting or removing the
  phone's bond.
- Post-pairing service discovery now replaces stale Bluetooth handles, and
  connection-stream errors are handled without escaping as app crashes.

## Pairing note

An AiDEX transmitter can be paired with only one phone at a time. If another
phone is already using the same sensor, keep the working phone connected or
stop that connection before moving the sensor. Do not reset an active sensor.

OpenGlucose is early-stage wellness/reference software, not a medical device.
Do not use it for diagnosis, medication or insulin dosing, treatment decisions,
or emergency monitoring.

App version: `0.1.1` (build `19`)
